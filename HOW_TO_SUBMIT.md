# Cách nộp bài

1. Vào GitHub và tạo repository mới.
2. Đặt tên repo, ví dụ: `postman-api-testing-practice`.
3. Upload toàn bộ các file trong thư mục này lên repo.
4. Mở Postman và import 2 file:
   - `Postman_API_Testing_Practice.postman_collection.json`
   - `Postman_API_Testing_Environment.postman_environment.json`
5. Chạy từng request và chụp ảnh kết quả.
6. Đổi tên ảnh theo danh sách trong thư mục `images`.
7. Upload ảnh vào thư mục `images` trên GitHub.
8. Copy link repo GitHub để nộp trên hệ thống và Google Sheet.
